# 临时策略检查点（2026-08-11）

**性质：临时。** 不是 ADR，不是产品承诺。供作者（Minhao）在「研究仪器 + 可演示产品」双轨上对齐判断。事实以当前树与已引用 arm 为准；数字必须带 arm / corpus，否则不可引用。

---

## 1. 现在什么是真的（事实页）

### 产品形态

- 研究代码，无生产用户；API 与 corpus 格式仍会变（README Project status）。
- 引擎：自然语言 → 只读 SQL → 确定性 layer stack 先检再跑；模型**不持有**数据库句柄。治理边界是**没有某类工具**，不是「请模型守规矩」。
- 语义层（corpus）与数据湖（obfuscated lake）是**外部 sibling 仓库**；本仓只服务它们。`corpus_content_hash` 是测量身份；勿往 corpus checkout 写生成物。
- UI 在独立仓 `governed-bi-ui`；本仓是引擎。

### 当前可引用测量（v4）

- Arm **v4**，corpus `BIRD-corpus` @ `30872d3`，1 351 题 / 57 schema：
  - 交付 EX **0.676**
  - 选择回答时准确率 **0.714**（n = 1 278）
  - 拒答 73（5.4%）；可计价 62 中 **77.4%** 若强答会错
- 拒答几乎全是检索上下文不足（19/20 终局 `r_table_not_licensed`；4 次 clarification 零 licensed），**不是**「会校准难度的 ML 弃权」。
- WrenAI 对照：同一 73 题全答、准确率 56.2% vs v4 承诺集上 WrenAI 68.5%——说明拒答集大多**可答**；abstention 跟踪的是**本引擎本回合是否够上下文**，不是题难。诚实标题窄于「calibrated abstention」（open-work §4.1）。
- 臂间比较用配对 McNemar / 不一致对，禁止用两个 EX 相减当结论；同配置不同 seed 可差 ~12.7% 题（SE(net) ≈ 1.0pp）。先定阈值再跑；先查机制再信分数（AGENTS / measurement）。

### 已拍板的产品边界（对话共识）

| 议题 | 决定 |
|---|---|
| RLS / RBAC | **不做进产品**；依赖 DB role |
| PII | 假定入站数据已脱敏；**暂不做** SELECT 级混淆 |
| 高风险决策 | **HITL + 工程审阅**，不做校准 ML 弃权产品化 |
| Demo | 改善可下载 DB 工作流；引擎+UI 单体感 / compose 体验要好看 |
| Corpus + lake | **继续外置** |
| 定位 | 跨平台 / 仓外 / 偏脏数据，对位 Cortex / Genie |
| 简历叙事 | Minhao；卖**判断力 + 治理拓扑**；谨慎抬高可答集质量；**EX 不当头条** |

### 引擎里真正值钱的性质

- 检索 miss → 可见拒答，而不是错表上的自信答案。
- 每次 turn 可审计：跑了什么、拒了什么、为什么。
- Deep Agents 已退役；`StateGraph` + `create_agent` 节点是既定形状。

## 2. 我们选择不当什么（边界页）

1. **不当仓内 Copilot。** 不跟 Cortex / Genie 比「贴着 warehouse 的原生体验」；卖的是仓外、跨平台、脏数据上仍可治理的查询路径。
2. **不当企业权限产品。** 不做 RLS/RBAC 栈；权限停在连接角色。把治理说成「行级安全」是定位污染。
3. **不当隐私清洗层。** 不做 SELECT obfuscation；PII 责任在入站。corpus `body` 里的字面量风险是合规债，不是当前卖点。
4. **不当校准弃权系统。** §4.1 已写明：拒答是「上下文不够」的机械后果，不是难度校准。高风险靠 HITL + 人审，不靠阈值分数演戏。
5. **不当 BIRD 刷榜机。** BIRD 是仪器不是产品。只抬 EX、却帮不了真实语义层客户的改动是缺陷。简历头条不是 EX。
6. **不当「假治理」叙事。** 禁止把 abstention precision 说成「知道哪些题难」。WrenAI 只能**框住**主张，不能**归因**；真正归因臂是放宽 Layer 6 allowlist、固定模型与 corpus（§4.2）——未做之前措辞保持窄。
7. **不当把 corpus/lake 吞进 monorepo「图省事」。** Demo 可 compose、可下载 DB；测量身份与资产外置不变。
8. **不当第二套「谁算 attempt / 预算是多少」实现。** 一层 stack、一个 register、一本 ledger；双读是本仓反复付过的税。

## 3. 接下来五步（排序 + 事前成功标准）

> 每条标准在动手**前**写下；数字出来后再改标准不算标准。双轨默认：**研究轨保仪器诚实，产品轨只包装已诚实的行为。**

### Move 1 — 对外叙事锁死 §4.1 窄表述（文档 / README / 简历）

**事前成功标准：**

- 凡出现拒答/弃权数字处，必须同时出现：「上下文不足」「priced subset 62」「非题难校准」。
- 禁止单独出现「calibrated abstention」作产品能力。
- README「How well it works」与简历一句，都能用同一窄句复述且不互相打架。

### Move 2 — Demo：可下载 DB + compose 一键路径（产品轨）

**事前成功标准（机制先于观感）：**

- 陌生人按文档能在本地拉起：**引擎 + UI + 一个可下载样例 DB**，无需手改 sibling 路径迷宫。
- Corpus / lake **仍外置或只读挂载**；compose 不把测量身份写进镜像层乱改。
- 一次成功路径：问一句 → 看到 SQL + 答案或拒答理由；拒答样例可复现（对齐 README 里 Clothing/profit 类失败）。

### Move 3 — 抬高可答集质量：检索 / licensing（研究轨，最大可赢桶）

**事前成功标准（先机制）：**

- 目标桶是 §1.5：gold 表未全部 licensed 的失败（跨结果 73），不是盲目抬 EX。
- 开跑前写下：将比较的 arm 名、是否 `--replay-routing`、McNemar 阈值（建议：净改善需显著于 pinned 噪声尺度，约 0.83pp SE 量级，具体 α 先写死）。
- 成功 = 该桶计数下降，且 abstention 构成仍可解释为检索；失败 = EX 动了但 licensed 覆盖/拒答直方图说不清。

### Move 4 — 高风险路径：HITL 可演示、可审计（产品轨）

**事前成功标准：**

- 一条「需人确认」路径：interrupt → 人答 → resume → 账本里能看见停过。
- **不**引入 ML 置信度阈值作门控；门控是规则/产品策略 + 人。
- 与现有 `ask_user` 澄清协议一致；不新开第二套 resume 语义。

### Move 5 —（可选研究）Layer 6 归因对照臂设计，先 ADR 后动手

**事前成功标准：**

- 书面 ADR：licensed = 检索预算 vs allowlist 是否解耦；对比臂只动 allowlist 宽度。
- 开跑前：样本、配对方法、接受/拒绝阈值写死。
- 在归因臂出数之前，对外话术**不升级**为「治理层独立贡献了 X pp」。

## 4. 双轨若腐蚀研究伦理：主要风险

1. **Demo 驱动改测量。** 为「演示好看」放宽 Layer 6、吞掉拒答、或改评分口径 → EX 好看但「miss → 拒答」性质没了。仪器坏了，产品故事是假的。
2. **把 §4.1 窄事实卖成宽能力。** 简历/Landing 写成「会弃权的智能」→ 对照臂与归因未完成时的过度宣称；被 WrenAI 式全答引擎一戳就穿。
3. **Monorepo / compose 图省事污染 corpus 身份。** 生成 store、样例写入 corpus 树 → `corpus_content_hash` 漂移，历史数字全部不可比；双轨里「产品便利」直接毁掉研究连续性。
4. **EX 成为隐形 KPI。** 双轨压力下默认「先涨分」；AGENTS 已判：只涨分、无真实语义层收益 = 缺陷。成功标准事后改写成「分涨了」是伦理破产的标准形状。
5. **第二实现 / 旁路治理。** Demo 热路径「先跑再说」、或 UI 侧另写一套 attempt/预算语义 → 审计账本与真实执行分叉；本仓已为「两个读者」付过税。
6. **权限/PII 叙事回潮。** 销售场合随口承诺 RLS 或 SELECT 脱敏 → 范围膨胀，研究主线（治理拓扑 + 可答集质量）被拖进企业平台工期。
7. **HITL 被做成置信度剧院。** 用未校准分数触发「人审」→ 看起来像产品成熟，实则假校准；与已否决的 ML abstention 产品化是同一错误的换皮。

**护栏一句：** 产品轨只能**展示**研究轨已测清的行为；任何改引擎行为的 demo 需求，先过测量教义（机制 → 事前阈值 → 配对检验），再谈发布话术。
